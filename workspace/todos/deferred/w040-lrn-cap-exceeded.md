### RT-001 — agent_sdk/routes/a2a.py
- severity: high
- description: The new A2A stream admission budget has no per-identity dimension, so one authenticated tenant can consume the entire global budget and lock every other tenant out of message:stream and tasks:subscribe. _A2AStreamRecord (a2a.py:86) stores only (task_id, owning_task, release) — no identity — and the only cross-tenant bound is _MAX_A2A_STREAMS = 500 (a2a.py:83). Add _MAX_A2A_STREAMS_PER_IDENTITY plus a _max_a2a_streams_per_identity(app) resolver reading an AGENT_SDK_-prefixed setting (mirror routes/mcp.py:187-197), enforced between the global check (a2a.py:347) and the per-task check (a2a.py:355). - codify: An admission cap whose only cross-tenant bound is a global counter is not isolation — every shared-budget stream route needs a per-identity dimension, and a per-resource sub-cap is vacuous when the route mints a fresh resource id per call.
