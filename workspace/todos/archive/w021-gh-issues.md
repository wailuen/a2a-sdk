- [x] `GH-71` acceptance-api.js A2A transport: fix URL path, remove JSON-RPC envelope, add messageId, update SSE event names ‖ group:G
  - Modifies: `harness/workflows/acceptance-api.js`, `template/.claude/workflows/acceptance-api.js` (lands via commit+push to wailuen/a2a-agent-template per LRN-071; runtime copy is what /acceptance actually executes)
  - Reads: `harness/workflows/acceptance-api.js`
  - Severity: high
  - Root cause: Four compounding bugs in the Python script generated by acceptance-api.js make every A2A scenario return -32602 or parse zero events. (1) URL path at lines 104 and 127 uses `/v1/message/stream` (slash); SDK route is `/v1/message:stream` (colon). (2) POST body is wrapped in a JSON-RPC envelope `{"jsonrpc":"2.0","method":"message/stream","id":"...","params":{...}}`; the endpoint accepts flat MessageSendParams directly. (3) The message object never includes `messageId`; SDK requires it and returns -32602 "check: message.messageId" when absent. (4) SSE event parsing checks `method == "taskStatusUpdated"` / `"taskArtifactUpdated"` (stale JSON-RPC notification style); actual stream events use `kind == "status-update"` / `"artifact-update"`.
  - AC:
    - URL path changed to `/v1/message:stream` (colon) at every occurrence — DONE
    - POST body is flat `{"message": {...}}` with no JSON-RPC wrapper — DONE
    - Message object includes `messageId` (uuid4) alongside `role` and `parts` — DONE
    - SSE event parsing uses `ev.get("kind") == "status-update"` and `ev.get("kind") == "artifact-update"`; payload field access updated to match the new event shape — DONE
    - At least one integration test or acceptance scenario passes end-to-end without -32602 / zero events — DONE (tests/test_gh71_acceptance_api_stream.py)
  - Deferred findings resolved:
    - RT-001 (high): filter(Boolean) fail-open — fixed: null results reified as synthetic failures; empty-results guard added; length assertion added
    - RT-004 (low): task_id not harvested from initial `kind == 'task'` frame — fixed: branch added at line 134
  - GH: https://github.com/wailuen/a2a-sdk/issues/71
